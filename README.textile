h2. Download

*Updating from a build made before v2.1.0?* Uninstall the old app once first. Builds are now signed with a fixed key, so later updates install over each other normally.

The APK is built automatically by GitHub Actions on every push. It is debug-signed, so your phone will ask you to allow installing apps from unknown sources.

Pedometer is an application for Android phones.

h2. Features

It counts your steps by using the sensors in the phone.

It calculates the pace (steps per minute), and can help you maintain a desired pace by speaking to you.

h2. New in v2.0

* *Amazfit watch support:* shows your watch's steps, distance and active calories. The Zepp app (or Zepp Life for older bands) syncs the watch to Health Connect, and Pedometer reads them from there. Turn it on in Settings > Amazfit watch.
* *Activity score (PAI-style estimate):* a weekly score from your watch's heart rate; aim for 100 or more a week. Zepp doesn't share its official PAI with other apps, so this is the app's own estimate and won't match Zepp exactly.
* *Calorie tracker:* daily calorie goal with progress on the main screen.
* *History:* daily steps and calories for the last 30 days, next to your watch's steps.
* Uses the phone's built-in step sensor when it has one (more accurate, far less battery), with the old accelerometer method as a fallback.
* Resets at midnight, keeps counting after a reboot, metric units by default.

h2. New in v2.3

* *Ready for Google Play:* targets Android 16, its own package name (@io.github.markybadz.pedometer@), a signed release bundle, privacy policy and store assets. See "docs/PLAY_STORE.md":docs/PLAY_STORE.md and "docs/PRIVACY.md":docs/PRIVACY.md.
* *Upgrading from an earlier build?* The package name changed, so v2.3 installs as a separate app. Uninstall the old Pedometer.
* Material 3 look on every screen, and a new app icon.
* Voice prompts follow your phone's language.

h2. New in v2.2

* *Google Health:* turn on Settings > Google Health > Share steps, and the phone's steps and distance go to Health Connect every 15 minutes, where Google Health (and other apps you allow) can show them. In Google Health, allow it to read steps from Health Connect.
* *Much better battery life:* counts with the phone's step-counter chip, which keeps counting while the phone sleeps, so the app no longer keeps the phone awake.
* *New Settings and History screens:* switches, current values at a glance, a weekly summary and daily progress bars.

h2. New in v2.1

* Fixes from an app audit: Quit no longer wipes today's steps, Pause stays paused, updates install over each other, and several crash and memory fixes. See "docs/AUDIT.md":docs/AUDIT.md for the full list and the gaps still open.
* Today's steps in the notification, and a notification when you reach your step goal.
* Watch steps show even if you allow only steps in Health Connect.
* Unit tests run on every build.

h2. FAQ

Question: How did you arrived at the formula for the step detection?
Answer: It's completely a result of experimentation. I know this is lame, but this was a weekend hack I made just for myself.

Question: How does the step detection algorithm work?
Answer: Basically, it aggregates the sensor values, finds the maximum and minimum, and if the difference is bigger than a value (which depends on the sensitivity setting) then it counts it as a step. There's is some additional optimization, which I arrived to through experimentation.

Question: In some other place, it says it's licensed under GPL, but here it says "No restrictions"; which one is true?
Answer: The one attached to the source code applies, so for this version "No restrictions". Previously it was under GPL, so some forks may still be under GPL.
